## Lo que aprendi en Ingenieria de Software 1
En esta asignatura aprendi el ciclo de vida del software, 
el levantamiento de requisitos funcionales y no funcionales, el uso de diagramas UML y 
la aplicacion de metodologias agiles como Scrum para agilizar diferentes 
tipos de proyectos segun el requerimiento del cliente. 
Tambien aprendi a usar Git y GitHub para el control de versiones.
